## A defect found while doing this

**79 pages had no mobile navigation at all.** The dock was being lifted from a
reference page with a search that matched the header's `</nav>` before the
dock's, so every page generated by `build-resources.mjs` shipped without one. The
stylesheet still reserved space for it, so those pages had a dead gap at the
bottom and no bottom nav on a phone.

Fixed at the source in `build-resources.mjs`, and the dock inserted into all 79.
All 203 pages now carry it.

The "193 broken internal links" that `audit-dist.mjs` reports against
`http-server` are that server issuing `301`/`302` from `/path` to `/path/`. Every
one resolves to 200 when followed, and the production nginx config sets
`absolute_redirect off` with `try_files $uri/index.html` ahead of the directory,
so they do not occur in the container.

## Rebuilding

```bash
cd local-site
node update-nav.mjs           # nav across every page, and the partials
node build-guides.mjs         # the Free Guides tree
node build-home.mjs           # homepage band order and contents
node build-patient-posts.mjs  # related posts on the patient libraries
node build-static.mjs         # -> dist/
node qa-new.mjs http://localhost:8099   # expect 0 problems
```

`build-patient-posts.mjs` must run **after** `build-resources.mjs`, which
regenerates those library pages from scratch. All four scripts are idempotent.
